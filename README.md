# 🐾 VetClinic - Sistema de Gestión Veterinaria

Sistema multiplataforma de administración para clínicas veterinarias construido con:

🌐 **Web** (React + TypeScript + Vite)
🖥️ **Desktop** (Neutralino.js)
📱 **Mobile** (React Native - API compartida)
🎮 **Interactivo** (Phaser - Canvas Virtual Pet)

## Inicio rápido

```bash
pnpm install
pnpm dev
```

## API Mock (desarrollo)

```bash

node scripts/mock-api-server.cjs
```
